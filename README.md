## 🧭 How I Work

I believe the right solution should be effective without being unnecessarily complicated — *don’t shoot sparrows with cannons*. I focus on choosing the right platform, APIs, languages, and tools for each challenge, with close collaboration and quality feedback throughout development.

My work spans software conception, engineering, project management, security, and long-term maintenance. I enjoy working independently and alongside teams, in agile environments or on focused project engagements.

## 🚀 Featured Projects

### [FFMpegGUI for macOS](https://jetedonner.github.io/posts/FFMpegGUIproject-swiftui/)

A high-performance, sandbox-compliant macOS audio and video processing suite. Use it to analyze, convert, heal, resample, and remux media files.

- **Platform:** macOS 14.0+
- **Language:** Swift 5.10+
- **Technology:** Swift, SwiftUI, Objective-C, XPC, FFmpeg API and binaries
- **License:** MIT

### [LLDBPyGUI](https://jetedonner.github.io/posts/LLDBPyGUI-Next-DevPreview/)

A Python-based graphical interface for the LLDB debugger. It brings executable and module analysis together with powerful debugging tools, including:

- Disassembly, process attachment, and target execution
- Module, library, section, and executable-header analysis
- Stack traces, breakpoints, watchpoints, registers, and variables
- Synchronized source view, memory viewer, and function search
- LLDB and Python consoles, command interfaces, and system-shell redirection

### [kundainfo.ch](https://kundainfo.ch)

A web app developed for the Social Department of the City of Zurich. It helps people find information about Zurich’s K&A locations, including regular and special opening hours, closures, and one-on-one situations. It also provides a way for clients to send feedback to staff.
